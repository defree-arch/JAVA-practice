# JAVA-practice
Homework
Practice №1 
Класс Матрица имеет 3 поля:
- Количество строк;
- Количество колонок;
- Данные (сами элементы, упорядоченные двумерным массивом).

Конструктор с проверкой на валидность размера матрицы.

Методы:
- set() считывает элемент по индексу;
- get() записывает элемент в матрицу по индексу;
- print_matrix() выводит матрицу в консоль;
- sum(Matrix B) суммирует матрицу с матрицей в аргументе;
- multiply(Matrix B) умножает матрицу на матрицу в аргументе;
- t() транспонирует матрицу;
- determinant() - вычисляет матрицу по методу Гаусса;
- division(Matrix B) делит матрицу на матрицу в аргументе;

* - inverse() вычисляет обратную матрицу, возвращает тип double[][] (вспомогательный метод, потом элементы округляются)
- clearConsole() чистит консоль (для более лучшего восприятия, несобственноручный метод)

Метод main:
1) Пользователю предлагается ввести сначала количество строк первый матрицы (матрица А), потом - количество колонок матрицы А. После чего вводятся элементы для матрицы, в одну строчку через пробел. После каждого завершения ввода требуется нажать "Enter" для дальнейших действий.
2) Со второй матрицей (матрица B) - аналогично.
3) После корректного ввода матриц, пользователю предлагается ввести операцию для введённых матриц: + (сложение), * (умножение), / (деление), t (транспонирование), d (нахождение детерминанта).

**Программа только на одну операцию (выравнивания вывода матрицы нет).
